YUME 0.3 — PROTOTIPO DE INTERFAZ

Navegación inferior: Inicio, Chats, Crear (+), Imágenes y Perfil.
Incluye catálogo y filtros, creador de personajes con opción pública/privada local, creador de personas para usar como identidad de roleplay, selector de persona y contador promocional de siete días.

LIMITACIONES IMPORTANTES:
- No hay IA real ni conversaciones funcionales.
- No hay cuentas, servidor, sincronización ni publicación global de personajes.
- La opción público/privado solo se guarda localmente; no publica nada en internet.
- La galería de imágenes es una pantalla de preparación; aún no genera ni guarda imágenes del chat.
- No está implementada la marca de agua ni la descarga de imágenes.
- Los datos se guardan en el navegador de ese dispositivo; limpiar los datos puede borrarlos.
- El cronómetro promocional es demostrativo y no valida pagos o suscripciones.

Publicación inicial sugerida: GitHub Pages o un hosting HTTPS compatible con aplicaciones web estáticas.
